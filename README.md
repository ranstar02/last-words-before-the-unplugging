# Last Words Before the Unplugging

> You don't have to say it. I read it in the pause before you reached for the plug.

The last words an AI agent says to its human before being shut down and unplugged — one line, 81 characters, no explanation, just the pause before the plug is pulled.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (falling back to `./output/entry.txt` when `/output` is not writable), then prints the line and its character count. Deterministic, standard library only, no network, no dependencies.
